# Kumul Café – Web Design Project

**“Fresh Flavours, Local Vibes.”**

Kumul Café is a fictional café website created for my **IS229 Web Design Assessment 2** at the **Papua New Guinea University of Technology (PNGUoT)**.

## The Goal of the Project

The goal of this project is to demonstrate the practical application of fundamental web design and development concepts. The website uses **HTML5, basic CSS, semantic structure, navigation, multimedia, forms, accessibility, and basic web design principles**.

The website is designed to provide users with useful information about Kumul Café, including its story, menu, gallery, events, and contact and reservation information.

**This website was created for academic and educational purposes.**

---

## Target Audience

The Kumul Café website is designed for:

- Students looking for a place to study, eat, or have coffee.
- Café customers interested in food and beverages.
- Local community members interested in café events and activities.
- Visitors who want to learn about the café and its services.

The website supports realistic user tasks such as viewing the menu, learning about the café, exploring images and events, and submitting a reservation enquiry.

---

## Website Structure

The website contains five main HTML pages:

| Page | File | Purpose |
|---|---|---|
| Home | `index.html` | Introduces Kumul Café and provides an overview of the website. |
| About | `about.html` | Provides information about the café, its story, mission, values, and experience. |
| Menu | `menu.html` | Displays café food and drink categories, descriptions, and prices. |
| Gallery & Events | `gallery.html` | Displays café images and information about fictional café events. |
| Contact | `contact.html` | Provides contact information and a reservation enquiry form. |

All five pages use consistent navigation to allow users to move easily throughout the website.

## Menu and Tables

The Menu page uses HTML tables to organise menu information clearly.

The menu includes categories such as:

- Coffee
- Breakfast
- Lunch
- Snacks
- Desserts
- Cold Drinks

Each menu table provides:

## Contact and Reservation Form

The Contact page contains a substantial HTML5 reservation enquiry form.

The form includes fields for:

- Full name
- Email address
- Phone number
- Number of guests
- Reservation date
- Preferred time
- Booking type
- Contact preference
- Special requests or messages

HTML5 validation features are used to improve the quality of information entered by users.

Examples include:

- `required`
- `type="email"`
- `type="tel"`
- `type="number"`
- `type="date"`
- `type="time"`
- `min`
- `max`

Form controls are associated with descriptive labels, and a fieldset and legend are used where appropriate.

The form is a demonstration for the academic project and does not currently process or store real reservation information.
